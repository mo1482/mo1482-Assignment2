# Calculator

A simple console calculator built using C# and .NET.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Input validation
* Division by zero handling
* Multiple calculations without restarting

## Technologies

* C#
* .NET
* Git
* GitHub

## How to Run

Clone the repository:

```bash
git clone https://github.com/mo1482/mo1482-Assignment2.git
```

Go to the project folder:

```bash
cd calculator
```

Run the application:

```bash
dotnet run --project Calculator
```

## Example

```text
Enter first number: 10
Enter second number: 5

Choose operation:
1. Addition
2. Subtraction
3. Multiplication
4. Division

Enter choice: 1

Result = 15
```

## Error Handling

The application handles invalid numbers and division by zero.

Example:

```text
Cannot divide by zero.
```
